# NO FIXED SHAPE

A short, dependency-free Python text puzzle based on the finalized door-challenge design.

## Play

Double-click `PLAY.bat`, or open PowerShell in this folder and run:

```powershell
python .\no_fixed_shape.py
```

Type `HELP` for commands. Type `THINK` for a contextual hint.

## Basic Interaction

- `LOOK`
- `EXAMINE <something>`
- `INTERACT WITH <something>`
- `MOVE <somewhere or somehow>`
- `THINK`
- `QUIT`

You can type short commands or complete sentences. The game accepts many synonyms, common spelling mistakes, object questions, and natural descriptions of intended actions.

## Test

```powershell
python .\no_fixed_shape.py --self-test
```
